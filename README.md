# UserRandom - UIKit + MVVM avec un Design System
Ce projet est une application iOS développée en Swift avec UIKit, sans Storyboard ni XIB, en utilisant l’architecture MVVM et un package Swift pour la gestion des composants UI.
## Objectifs du projet

- Utilisation de l’architecture MVVM pour une meilleure séparation des responsabilités.  
- Développement de l’interface utilisateur en UIKit, entièrement en code.  
- Création d’un package Swift dédié aux composants UI réutilisables.  
- Mise en place de tests unitaires pour garantir la fiabilité du code.

### Installation du package via Swift Package Manager

Le package est disponible via Swift Package Manager et peut être ajouté avec l’URL suivante :

https://github.com/walidIos/DesignSystem.git
Ajoute le package via **Swift Package Manager** :  

1. Ouvrir Xcode → `File > Add Packages...`  
2. Entrer l’URL: https://github.com/walidIos/DesignSystem.git
